큐플레이 아카이브

넥슨 메이플월드 기반 큐플레이 아카이브 아장위키

게임 정보
개발 갈곳잃은개
플랫폼 Windows, macOS
Android, iOS

출시일 2024년 11월 22일
최대 플레이어 채널당 100명

1. 개요

2024년 11월 22일 20시 서비스를 시작한, 넥슨 메이플월드(MapleStory Worlds) 기반으로 개인 개발자가 개발 및 운영 중인 큐플레이 프리서버(이하 아카이브).

2015년 넥슨이 운영한 큐플레이 본서버(이하 본서버) 종료 당시 최종 클라이언트를 보유하고 있던 한 유저가 아카이브 개발자에게 자료를 제공했고, 개발자가 이를 토대로 리소스를 분석·복원해 아카이브를 구축했다.

이전에도 큐플레이를 표방한 메이플월드 서버들이 존재했으나, 아카이브가 본서버의 구현률이 가장 높다는 평가를 받으며 이주 유저, 복귀 유저, 신규 유저들이 대거 유입되었다. 아카이브는 본서버의 UI와 기본 구조를 유지하면서도 신규 상점, 신규 아이템, 랭킹 페이지, 기타 편의 기능 등을 원작 분위기를 해치지 않는 범위에서 추가하고 있다.

메이플월드를 통해 서비스되므로 PC·모바일 기기에서 모두 플레이 가능합니다.

3. 개발자

큐플레이 아카이브 개발자는 1인 개발자이자 운영자로, 다음과 같은 별칭으로 불립니다.

  • 갈곳잃은개 : 메이플월드 개발자 닉네임
  • 프리렌 : 유튜브 계정명
  • 큐플폴리스 : 큐플레이 아카이브 게임 닉네임

개발자 문의처

신고, 버그 제보, 건의사항을 접수합니다. (채팅신고는 인게임 UI에서 가능)

qplayarchive@gmail.com

* 이메일 작성 시 본인 닉네임을 반드시 기재해야 합니다.

4. 설치 및 하는 법

캐릭터 생성 절차

  1. 넥슨 계정 생성: 넥슨 계정이 없다면 회원가입 진행
  2. 넥슨 OTP 설정: 미설정 시 접속 불가
    ※ OTP 설정 방법 안내
  3. 메이플월드 설치 및 가입: 넥슨 계정 연동
  4. QPlay Archive 월드 접속: 메인 월드에서만 캐릭터 생성 가능 (검색어: '갈곳잃은개', 'Qplay')
  5. 캐릭터 생성
    • 메인 아이디는 추후 변경 불가능
    • 서브 아이디(게임 내 닉네임)는 추후 변경 가능 (100,000 사이버머니)
    • 큐피몬 선택 가능
    • [확인] 클릭 시 별도 안내창 없이 즉시 생성됨

회원가입 및 탈퇴 관련

  • 주민등록번호 기준 최대 3개의 넥슨 계정 생성 가능
  • 넥슨 1계정당 메이플월드 계정 1개, 큐플레이 아카이브 캐릭터 1개만 생성 가능
  • 아카이브 내 캐릭터 삭제 기능이 없음. 삭제 원할 시 메이플월드 계정을 탈퇴해야 함
  • 메이플월드 탈퇴 시 15일 유예기간 후 동일 계정 재가입 가능

5. 게임 규정

자세한 내용은 아카이브 공식 디스코드 [월드제재규정] 채널에서 확인 가능합니다.

공식 규정 (주요 금지사항)

  • 비인가 프로그램 사용 (매크로, 오토마우스, 키맵핑, 멀티터치 등)
  • 정보 도용과 유출 행위
  • 월드 이용 방해 (욕설, 사행성 조장 등)
  • 사기 행위
  • 상업적 홍보 및 광고
  • 게임 오류 악용
  • 부적절한 거래 (아이템 매니아, 현금거래 등)

운영자 추가 규정

  • VPN 해외 서버 생성하여 지인 이동 플레이 (30일)
  • 앱플레이어 멀티터치 등 매크로로 재화 부당 획득 (영구)
  • 타 게임 재화/계정 등과 교환 및 시도 (영구)
  • 개인정보, 허위사실, 게임 무관, 홍보 목적의 문제 출제 행위
    1차 30일 / 2차 90일 / 3차 365일 / 4차 영구정지

9. 단축키 및 명령어

단축키

  • F1 : 정답 1 (O) 선택
  • F2 : 정답 2 (X) 선택
  • F3 : 정답 3 선택
  • F4 : 정답 4 선택
  • F8 : 친구창
  • F9 : 길드창
  • Ctrl + F : 사용자 찾기
  • Ctrl + I : 사용자 초대
  • Ctrl + O : 옵션창
  • Ctrl + G : 길드창
  • Ctrl + M : 쪽지창
  • / : 채팅 입력 커서 활성화
  • 1~4 : 객관식 문제 정답판 들기 (중복 입력 가능)

명령어 (채팅창 입력)

  • /모두에게 : 전체 채팅 변경
  • /길드에게 : 길드 채팅 변경
  • /귓말 (닉네임) : 귓속말로 변경
  • /확성기 : 확성기 UI 열기
  • /확성기 (내용) : 확성기 즉시 송출
  • /쪽지 : 쪽지창 열기
  • /길드 (길드명) : 해당 길드 정보창 열기
  • /친구 : 친구창 열기
  • /정보 (닉네임) : 정보창 열기
  • /무시 (닉네임) : 블랙리스트 추가
  • /무시해제 (닉네임) : 블랙리스트 해제
  • /돈주기 (닉네임) (금액) : 사이버머니 주기
  • /방제변경, /방비번변경
  • /들어가 : 매직이펙트 끄기
  • /커플이다 : 커플 이펙트 실행

10. 아이템 상점 및 거래 시스템

상점 종류 및 업데이트

  • 일반 상점 : 상시 판매 (사이버머니/캐시). 삭제되지 않고 영구 판매됨.
    ↳ 업데이트: 매월 셋째 주 (혹은 넷째 주)
  • 요술 상자템 : 유일한 기간 한정 판매 일반 상점 (테마 카테고리, 캐시 구매).
    ↳ 업데이트: 매월 둘째 주
  • 큐포인트 상점 (큐뽑) : 기간 한정 랜덤 뽑기. 캐시 충전 시 10% 큐포인트 환급, 600P당 1회 (확률 동일).
    ↳ 업데이트: 매월 첫째 주

* 일정은 고정이 아니며 통상 목, 금, 토 중 결정되어 디스코드로 사전 공지됩니다.

거래(교환) 제한 시스템

모든 상점 아이템은 유저 간 거래(교환)가 단 1회만 가능합니다.

  • 선물하기, 개인샵, 교환방을 통해 이동 시 남은 거래 횟수가 0이 되어 이후 거래 불가
  • 출석체크 보상 등 일부 아이템은 획득 시점부터 즉시 거래 불가 상태

11. 기타 게임 정보

분장실 정보

  • 성전환 시 슬라임 포함 모든 착용 아이템 해제 필수
  • 가방 외 아이템 창고 존재 (기본 9칸)
  • 분장실/창고 [설정] 버튼으로 거래불가 아이템 시각적 구분 가능
  • 휴지통에 넣은 아이템은 직접 [삭제] 누르기 전까지 보존

유저 기능 정보

  • 귓속말, 길드채팅은 월드 무관 전송 (확성기는 동일 월드만)
  • 커플 해지는 동일 채널에서만 상호 해지 (아니면 누른 사람만 해지)
  • 친추, 옷보기, 초대, 돈주기, 선물하기는 동일 채널만 가능
  • 블랙리스트 (미접속자도 가능): 채팅/확성기 차단, 귓속말 차단, 방 입장 차단

아이템 관련 주의사항

  • 정답률쉴드: 가방에서 클릭해 활성화. 유효기간 누적 연장.
  • 매직이펙트: 유지형/발동형 존재. 선물 불가 (캐시 직접 구매).
  • 큐피몬: 상점 재판매 불가 (개인샵 거래는 가능).
  • 정보꾸미기: 사용 즉시 소모(영구 유지). 초기화 시 기본패턴 구매 필요.
  • 개인샵 이용권: 성별이 다르면 사용 불가.

성별 무관 아이템 (남녀 공용)

펫, 매직아이템(정답판), 확성기, 정답률쉴드, 엠블럼쓱싹이, 엠블선택쓱싹, 정답률초기화, 경험치초기화, 게임레벨리셋, 부활카드
※ 단, 공용 템이라도 받는 사람과 성별이 다르면 "선물하기"는 불가. 개인샵/교환방 이용 필수.

12. 유저 이용 Tip

게임 이용 팁

  • 모든 공식 정보/소통/거래는 디스코드 위주로 돌아감.
  • 캐시 아이템 시세는 1:3 비율 (캐시:사이버머니)이 일반적. 발품 팔면 더 쌈.
  • 경쟁 방 입장 시 방 누르기보다 [바로시작] 버튼 연타가 빠름.
  • 서바이벌 솔플 시 부계정 입장 후 퇴장시키는 행위는 치팅 아님.

메이플월드 관련 팁

  • 지정기기 등록: OTP 인증 생략 가능 (PC 3대, 모바일 10대).
  • 넥슨ID 메월 친구 추가 시 [같이 플레이하기]로 채널 따라가기 가능 (풀방이어도 재시도 뚫기 가능).
  • 메월 서버 점검은 큐플레이 아카이브와 별개로 진행.

슬라임 아이템 가성비 세팅 팁
